## 香港服务器的价格差，主要差在带宽口径上

市面上大量“香港服务器”卖的是 2–30Mbps 独享带宽，而 GoMami 这类商家卖的是 1–5Gbps 端口 + 单向流量。两者计价单位不同，价格没法直接横向比。

再看 1Gbps 这一档：DMIT 香港 1 核 1G / 20G / 100Mbps / 400GB 的 CN2 GIA 方案 $39.9/月起，搬瓦工香港 2 核 2G / 40G / 1Gbps / 500GB 的 CN2 GIA 方案 $90/月起。GoMami 香港 Pulse Nano（2 核 2G / 40G / 500GB / 1Gbps）$49/月，基本落在同一个价格带。

所以判断香港服务器贵不贵，先看三件事：端口带宽是共享 Gbps 还是独享几兆、流量是单向计还是双向计、回程走哪条线。这三项对上号了，价格才有可比性。

## 四个只写在文档里、但会直接影响账单的条款

**只计算出站流量。** 入站完全免费。对建站、图床、下载站这类“用户下载多、上传少”的业务，这个口径比双向计费省不少。如果你的业务是反向的（大量上传、备份回源），优势就没那么明显。

**超限是限速，不额外扣费。** 月流量用完后会被限速，额度在下一个计费周期开始时重置，具体限速策略按产品规格而定。官方没有公开统一数值，网上流传的“限速到 20 KB/s”是第三方说法，下单前不要把它当承诺。

**流量包只在当前周期有效。** 不够用可以单独买，价格是 100GB $6、500GB $30、1TB $60、2TB $120、5TB $300、10TB $600、20TB $1200，但买了不会结转到下个月。官方自己的建议是：如果长期流量吃紧，直接升级更高档套餐更划算。

## 三条需要提前知道的限制和争议

线路宣传存在个案争议、部分档位经常缺货、升配不能自助——这三点会影响实际体验，下单前值得知道。

线路方面，主流的第三方测评结论是晚高峰仍能跑满标称速率，也有实测记录显示香港 Pulse 节点下行跑到过 995 Mbps。但也有用户在 GitHub 上投诉，称花 $99 买的香港服务器实际回程走的是 163 骨干而非宣传的 CN2/9929，且未获退款。这条投诉是单一节点、单一时段的 traceroute 结果，没有独立复现，不能当定论；不过它提醒了一件事——线路判定涉及测试方法、时段和 IP 段多个变量，别人测出来什么样，不等于你分到的 IP 也那样。用测试 IP 自己跑一遍回程，比看任何测评都可靠。

库存方面，日本 Pulse 的 Nano 和 Mini、香港 Forge 两个档位在近期抓取中显示缺货，香港 Turin 和 Pulse 的主力档位有货。库存随时会变，深折扣码也常常是“补货刚开时能用、库存吃紧就失效”。

运维方面，目前升降配需要开工单联系客服，控制面板没有自助变更入口；长期满载 CPU 可能被判定为 noisy neighbor 而触发性能限速。这些不影响正常使用，但和某些云厂商“点两下就升配”的体验不一样。

## 下单流程和两个容易出错的环节
